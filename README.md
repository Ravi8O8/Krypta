## 💡 О проекте

**Krypta** — это полностью офлайн-медиатека. Все ваши фото и видео хранятся **только на вашем устройстве**, в приватной файловой системе (OPFS) и IndexedDB. Никаких серверов, никакой синхронизации, никаких аккаунтов.

> ⚠️ **Это тестовый проект.** Он создан для проверки идей и демонстрации возможностей Capacitor + Web APIs. Не рекомендуется для хранения критически важных данных.

> 🤖 **Сделано при помощи [DeepSeek](https://deepseek.com).** Весь код, архитектура и решения написаны в паре с ИИ-ассистентом.

## ✨ Возможности

- 📁 **Папки с цветами** — организуйте медиатеку как удобно
- 🏷️ **Теги и избранное** — быстрый поиск по метаданным
- 🗑️ **Корзина с автоочисткой** — ничего не теряется случайно
- 🔍 **Поиск по имени и тегам** — мгновенный фильтр по всей библиотеке
- 🎞️ **Слайдшоу и рандом** — просмотр фото в один клик
- 🔐 **Пароль на вход** — PBKDF2 + SHA-256
- 📤 **Экспорт в ZIP** — полный бэкап библиотеки
- 📥 **Импорт из ZIP** — с сохранением структуры папок
- 🖼️ **Скачивание файлов** — нативно через системное меню Android
- 🎨 **18 тем** — от AMOLED до Sakura
- 🖼️ **Кастомный фон** — своё изображение с прозрачностью

## 🛠️ Технологии

| Слой | Стек |
|------|------|
| **Frontend** | Vanilla JS, HTML5, CSS3 (без фреймворков) |
| **Хранилище** | OPFS + IndexedDB |
| **Упаковка** | Capacitor 6 |
| **Плагины** | `@capacitor/filesystem`, `@capacitor/share` |
| **Сборка** | GitHub Actions → APK |
| **Криптография** | Web Crypto API (PBKDF2, SHA-256) |

## ⚠️ Ограничения

- 🚫 **Экспорт больших архивов (2+ ГБ)** может привести к вылету по OOM. Разбивайте библиотеку на части.
- 🚫 **Пароль защищает только интерфейс**, а не шифрует данные на диске.
- 🚫 **Нет облачной синхронизации** — это осознанное решение.
- 🚫 **Тестовый статус** — не используйте как единственное хранилище важных фото.
